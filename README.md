📌 PROJECT OVERVIEW
This Excel project analyzes food delivery order data and presents key insights through an interactive and visually appealing dashboard.

📂 DATASET
• 📊 Dataset: Food Delivery Orders
• 🔢 Total Records: 200
• 🧾 Key Fields: Order ID, Customer ID, Restaurant, Cuisine Type, Order Cost, Day of Week, Rating, Food Preparation Time, Delivery Time

📑 SHEET ORGANIZATION
• 📥 Raw_Data – Original dataset
• 🧹 Cleaned_Data – Cleaned and prepared dataset
• 📊 Pivot Tables – Pivot-based analysis and KPI calculations
• 🧮 Analysis – Advanced Excel formulas and analysis
• 🎯 Dashboard – Interactive data visualization and KPIs
• 📖 Documentation – Project information and instructions

🧹 DATA CLEANING
• ✅ Checked Order IDs for duplicate records
• 📝 Handled missing Rating values using N/A
• 🔍 Verified numerical and data formats
• ✨ Prepared the dataset for analysis

🧮 ADVANCED EXCEL ANALYSIS
• 🔎 VLOOKUP
• 🔗 INDEX-MATCH
• 🧠 IF / Nested IF
• 📊 Pivot Tables
• 🎯 KPI Calculations

📈 VISUALIZATION
• 🍽️ Orders by Cuisine Type
• 🏆 Top 5 Restaurants by Orders
• 📅 Orders by Day of Week
• ⭐ Rating Distribution
• 🎯 KPI Cards

🎛️ INTERACTIVE DASHBOARD
• 🍴 Cuisine Type Slicer
• 📅 Day of Week Slicer
• ⭐ Rating Slicer
• 🔄 Connected PivotTables and PivotCharts
• 📊 Dynamic KPI values based on selected filters

💡 HOW TO USE
Use the slicers on the right side of the Dashboard to filter the data. The KPI cards and charts automatically update according to the selected filters.

🎯 PROJECT OBJECTIVE
The objective of this project is to clean, analyze, visualize, and present food delivery data through an interactive, informative, and easy-to-understand Excel dashboard.

🚀 PROJECT HIGHLIGHT
Transforming raw food delivery data into meaningful insights using Excel's data analysis, visualization, and interactive dashboard capabilities.
